# KiwiStressDB

KiwiStressDB（猕猴桃胁迫组学数据库）整合猕猴桃高温、低温、病原侵染、盐胁迫和涝害相关的内部研究记录、公开文献与基因组资源。

当前版本：v0.2（2026-09-25）

## 数据原则

- 只展示可追溯的内部实验记录或公开文献。
- 尚未公开或尚未导入的表达矩阵、序列及数据库编号统一标记为“待接入”。
- 不使用模拟表达量、模拟单细胞图或虚构登录号。

## 本地查看

直接打开 `dist/index.html`，或使用任意静态文件服务器托管 `dist/` 目录。

## 部署

仓库包含 GitHub Pages 工作流；发布内容来自 `dist/`。
